# Guardian News — Стрічка новин

Мобільний застосунок на Android (Jetpack Compose) для читання актуальних новин за обраним розділом, перегляду карток статей з ілюстраціями та локального збереження обраних матеріалів на пристрої.

## Опис проєкту (одне речення)

Застосунок дозволяє читати свіжі новини [The Guardian](https://open-platform.theguardian.com/) за обраним розділом, переглядати детальні картки статей з обкладинками та зберігати цікаві матеріали для читання на пристрої.

## Перелік екранів

| № | Екран | Призначення |
| :--- | :--- | :--- |
| 1 | **Каталог (Стрічка новин)** | Відображення списку новин за обраним розділом або пошуковим запитом із мініатюрами зображень (`fields.thumbnail`). |
| 2 | **Деталі (Картка статті)** | Повна інформація про статтю: заголовок, розділ, дата публікації, обкладинка, посилання на оригінал та кнопка додавання в збережені. |
| 3 | **Збережені матеріали** | Перегляд і видалення статей, збережених користувачем у локальній базі даних пристрою. |
| 4 | **Налаштування** | Вибір розділу новин за замовчуванням (наприклад, `technology`, `world`, `science`, `sport`) та параметрів стрічки. |

## Джерело даних (REST API)

* **API**: [The Guardian Open Platform](https://open-platform.theguardian.com/documentation/) (публічний REST API без OAuth, підтримує навчальний ключ `test` та власний безкоштовний ключ розробника).
* **Тестовий запит**:
  ```text
  https://content.guardianapis.com/search?q=android&show-fields=thumbnail&page-size=20&api-key=test
  ```
* **Масив об'єктів у JSON-відповіді**: `response.results` (кожен елемент містить поля `id`, `sectionName`, `webPublicationDate`, `webTitle`, `webUrl` та об'єкт `fields`).
* **Поле із зображенням**: `fields.thumbnail` (повертається за наявності параметра `show-fields=thumbnail`).
* **Ліміт запитів ([Developer Key](https://open-platform.theguardian.com/access/))**:
  * До **1 запиту на секунду** (1 call per second).
  * До **500 запитів на добу** (500 calls per day).
  * *Примітка для Лабораторної роботи №10*: через обмеження у 1 запит/сек під час одночасних (паралельних) запитів на тестовому/безкоштовному ключі сервер може повертати код `429 Too Many Requests`, тому для паралельних запитів буде використано чергу або обмеження конкурентності.

## Що зберігається локально на пристрої

* **Розділ новин за замовчуванням**: зберігається у `DataStore` / `SharedPreferences`, щоб при відкритті застосунку одразу завантажувалась улюблена рубрика.
* **Збережені статті (закладки)**: зберігаються у локальній базі даних `Room` (заголовок, дата, рубрика, URL мініатюри та посилання на статтю) для швидкого доступу без повторного пошуку.

## Технологічний стек
